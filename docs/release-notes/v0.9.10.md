# AI Chat Shell Exec v0.9.10

This release keeps the floating panel's active Role and its actual tmux routing aligned across page refreshes, and makes `Reset tmux` operate on only that role's workspace.

## What changed

- None/Master/Slave activation now lives in extension-owned per-tab session storage. A page reload restores the same active profile even if the site clears its own `sessionStorage`, while a separate tab remains unconfigured until explicitly saved.
- Shell helpers, board helpers, startup checks, server checks, and full-chain tests consistently use `ForAI-<agentId>` for an active Master or Slave role. Role=None continues to use the default `ForAI` workspace.
- The floating panel's `Reset tmux` action resets only `ForAI-<agentId>` for an active agent role, or only `ForAI` for Role=None. Other agent and default sessions are left intact.
- Server protocol 8 makes role-scoped tmux ensure/reset and board routing explicit, preventing a newer extension from silently using an older server's default-session behavior.

## Validation

- Full `./scripts/test_all.sh` suite.
- Real Chromium unpacked-extension E2E that clears page session storage, reloads, executes in `ForAI-slave-a`, resets that session, and proves the default `ForAI` pane is unchanged.
- Focused content/background profile hydration and routing tests plus private-tmux exact-session reset integration coverage.

## Upgrade notes

- Restart the foreground shell server after updating because this release requires server protocol 8.
- Reload the unpacked extension and refresh enabled chat tabs.
