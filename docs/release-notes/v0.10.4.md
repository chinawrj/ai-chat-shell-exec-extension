# AI Chat Shell Exec v0.10.4

This release refines the compact extension panel's output-idle decision state and makes every important state visible directly in the README using screenshots captured from the real unpacked-extension Chrome E2E flow.

## Documented panel states

- Healthy idle keeps only concise status and `More` visible.
- A rendered helper exposes contextual `Force run`.
- Active shell execution replaces Force run with `Stop helper`.
- Output-idle state places `Continue waiting` and the same `Stop helper` action side by side in the exact-run decision card, with the redundant upper Stop control hidden.
- `Draw.io preview` appears only when a preview artifact or render error is available.
- Draw.io replacement previews render in a transparent, noninteractive offscreen staging layer so Chromium reliably completes SVG layout before the atomic swap.
- `More` reveals all classified setup/recovery, binding, Agent/tmux-ai, status, and diagnostic controls.

## Validation

- The real Chrome E2E generates every screenshot only after its corresponding UI-state assertion passes.
- A dedicated README regression test verifies every referenced image exists, is a valid PNG, has bounded panel-crop dimensions, and remains connected to its E2E generation point.
- Draw.io streamed-render timeouts now include preview, iframe, candidate, debug, and browser-console state for actionable diagnosis without weakening the render assertions.

## Compatibility

Server protocol remains 10 and helper protocol remains 3. Reload the unpacked extension and refresh affected chat tabs after updating; no protocol-driven shell-server restart is required.
