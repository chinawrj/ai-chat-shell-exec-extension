# AI Chat Shell Exec v0.11.3

This release keeps the floating panel compact while making its Skills, page-binding, and active-role states clearer.

## Skills catalog access

- An acknowledged gray `Skills vN` chip is now enabled. Clicking it opens the complete local Skills catalog, including a valid zero-item catalog.
- Local catalog viewing does not create a synchronization challenge, change the acknowledgement, write to the chat composer, or send anything to the AI.
- The green update chip still starts ordinary synchronization, the syncing chip remains disabled to protect multi-tab ownership, and the red invalid state opens local diagnostics.

## Compact role and advanced controls

- The existing top status row now includes a 20px `None`, `Master`, or `Slave` badge. Text always identifies the role; distinct neutral, blue, and purple colors do not reuse green update or red error semantics.
- The badge reflects only the saved active profile. Editing the advanced role selector does not change it until Save succeeds, and its accessible label reports the exact tmux target.
- Page binding is now the last advanced group and is collapsed by default through a native details control. `Bind input`, `Bind send`, `Bind shell`, and `Clear` remain unchanged.

## Validation

Focused tests and the real unpacked-extension Chrome E2E cover current/update/syncing/invalid Skills states, zero-Skill local viewing without AI output, default and saved role labels/colors/targets, unsaved-role isolation, refresh and disable transitions, compact non-overlap, advanced order, and Page binding expansion. The README screenshots were regenerated through the same real Chrome path.
