# AI Chat Shell Exec v0.9.11

This release prevents interactive or otherwise silent shell helpers from occupying a role's tmux pane without giving the user a safe way to intervene.

## What changed

- The shell timeout is now an output-idle timeout. Its default is 3 minutes, and each observable output update resets the clock.
- Reaching the idle limit no longer creates a timeout result or silently kills the command. The run enters `awaiting-user`, and the floating panel offers `Continue waiting` or `Force terminate`.
- The floating panel now includes `Stop helper`, which can terminate the active shell helper at any time.
- Continue resets the idle clock. Termination resolves the active None/Master/Slave role, revalidates the immutable tmux pane owner, interrupts that helper, and escalates only its foreground process group when Ctrl+C is insufficient.
- Idle decisions survive service-worker loss, page refresh, and shell-server recovery through persistent ledger and tmux-owner metadata.
- Existing installations still using the old 30-second default migrate to 3 minutes; custom timeout values are preserved.
- Server protocol 9 adds streamed shell progress and role-scoped status/continue/terminate control messages.

## Validation

- Full `./scripts/test_all.sh` suite.
- Private-tmux integration coverage for output-driven idle resets, idle notification, Continue, repeated idle intervals, role isolation, and exit-130 termination.
- Real Chromium unpacked-extension E2E that opens the idle alert, clicks Continue, receives a second alert, clicks Force terminate, and verifies the shell result.

## Upgrade notes

- Restart the foreground shell server because this release requires server protocol 9.
- Reload the unpacked extension and refresh enabled chat tabs.
