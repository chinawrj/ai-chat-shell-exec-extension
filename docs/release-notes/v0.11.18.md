# AI Chat Shell Exec v0.11.18

Fixes board helpers returning `Board prompt probe failed; command was not sent.` when a ready tmux pane has a long history.

## Cause and fix

The old probe captured up to 20,000 history lines but retained the first 80,000 characters, after an additional 1,000,000-character subprocess limit. The current prompt at the end could disappear from the probe, and old prompt-shaped text could be mistaken for current state.

Board readiness now captures the current screen plus one preceding boundary row. The history count and capture are read in one tmux command list; when history exists, the first joined logical line is discarded, including any soft-wrapped continuation into the screen. Historical text and clipped long lines cannot become short false prompts. It compares two complete, bounded snapshots across the probe idle interval and rejects incomplete captures. Command-result output limits are independent of readiness. Shell-backed boards retain foreground-process checks and exact pane revalidation; queue ownership, recovery, and command deduplication behavior are preserved.

A stable recognizable prompt is still required. A changing screen, promptless pane, busy shell, or screen exceeding the bounded probe capacity remains ineligible. Generic board prompt text is not authoritative execution proof.

## Validation

- Reproduced the exact original failure in real tmux with 192,016 characters of history before changing the server.
- Real-tmux regressions cover history beyond both 80,000 and 1,000,000 characters, one actual command execution, current output without historical contamination, and successful prompt detection with a 16-character result limit.
- Independent focused tests cover stale historical prompts, incomplete snapshots, prompt length boundaries, screen changes despite identical prompts, busy shells, pane replacement, and capture failures.
- Full automated suite: `./scripts/test_all.sh`, including real Chromium extension E2E.

## Installation

Download the source ZIP for the updated local server, restart the foreground server, reload the unpacked extension, and refresh affected chat tabs. Both ZIP assets are accompanied by `SHA256SUMS.txt`.
