# AI Chat Shell Exec v0.10.3

This release makes the floating extension panel substantially smaller by default without removing its setup, recovery, Agent, tmux-ai, Draw.io, or diagnostic capabilities.

## Compact default panel

- The panel now uses a compact 292px default width with a single-line status and state indicator.
- Normal idle shows only status and `More`; errors add `Server Check`, a runnable helper adds `Force run`, and active shell execution replaces Force run with `Stop helper`.
- Long status text remains available in the advanced diagnostics area and through accessible status metadata.
- The existing per-origin drag position continues to work.

## Classified advanced controls

`More` reveals every previous control under four labelled groups:

- Setup & recovery: an always-available Server Check, Test, site enablement, role filter, and role-scoped tmux reset.
- Page binding: input, send, and shell binding plus Clear.
- Agent & tmux-ai: page agent profile, roster/setup checks, target refresh, and registration.
- Tools & diagnostics: full status and detected-helper debug details.

Draw.io uses a contextual shortcut instead of a permanent advanced control. It stays hidden until a preview artifact or error log exists, then remains available to reopen the preview after Close.

## One stop concept

- `Stop helper` is hidden while no helper is active and shown during a real shell helper run.
- Output-idle `awaiting-user` state adds only `Continue waiting`; the same common `Stop helper` terminates the exact waiting execution after confirmation.
- This removes the redundant user-facing `Force terminate` label without changing server-side owner, execution, pane, or foreground-process-group revalidation.

## Validation

- Source-level coverage locks the compact width, state-driven common actions, default collapsed state, advanced group structure, preservation of every previous action, and active-only Stop behavior.
- Real Chromium E2E verifies More-only idle startup, expansion and collapse, all advanced controls, Force/Stop replacement, contextual Draw.io appearance plus Close/Reopen, Continue waiting, and an exit-130 interruption through the common Stop helper.
- The full static, unit, tmux integration, packaging, and Chromium extension suite is required before release.

## Compatibility

Server protocol remains 10 and helper protocol remains 3. Reload the unpacked extension and refresh affected chat tabs after updating; the shell server does not require a protocol-driven restart for this UI-only release.
