# AI Chat Shell Exec v0.11.19

Draw.io previews now include **Copy PNG** and **Download PNG**. The exported image uses the current page’s complete diagram bounds at natural 1× scale with a white background, without preview controls or blank paper margins. HTML labels and shapes away from the origin are included.

Multi-page `.drawio` files now show a persistent named **Page** selector and **Previous/Next** buttons. The navigation buttons disable at the first and last page. PNG export follows the selected page and uses its name; closing and reopening the preview preserves that selection. **Download .drawio** continues to save the full original document.

Exports remain local to the sandbox. Only trusted clicks can copy or download PNGs. Replies are tied to the exact frame, request, artifact, and page revision; switching pages, closing, navigation, or a newer helper cancels pending results. Clipboard/export failures remain local, leaving the SVG and original-file download available.

On hosts with restrictive nonce-based CSP, the trusted sandbox wrapper applies label styles through CSSOM before measuring them. HTML labels remain visible and exports retain tight content bounds; the host CSP, sandbox permissions, and pinned vendor assets remain unchanged.

Limits: 8192 pixels per side, 16 megapixels, 8 MiB serialized SVG, 32 MiB PNG. Oversized exports report an error rather than silently shrinking. If clipboard permission is unavailable, use Download PNG.

Validation: focused positive, negative, boundary, timeout, and lifecycle tests; real unpacked-Chrome PNG dimensions/pixels, actual clipboard copy, page selection, and nonce-srcdoc CSP export; full automated suite.

Assets: unpacked Chrome extension ZIP, complete source ZIP, and SHA256SUMS.txt. Unzip the extension ZIP and reload it in chrome://extensions. Existing settings are preserved.
