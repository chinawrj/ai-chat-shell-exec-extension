# AI Chat Shell Exec v0.11.21

Every complete non-user Draw.io helper now has two trusted **Preview** controls: one above its start and another below its `ai-helper-drawio-end` marker. Both open the exact same diagram, so a long helper can be previewed without scrolling back to its beginning.

The two controls share the existing route, lifecycle, rendered-root, semantic-payload, block-position, settings, and trusted-click checks. Historical previews stay local: they do not process Skills, contact the shell backend, or write success or failure into the chat composer.

When one code block contains multiple Draw.io helpers, matching **Preview 1**, **Preview 2**, and later controls remain in reading order at both the start and end boundaries. Repeated scans reuse both controls. If either control disappears or becomes stale, the pair is rebuilt without moving or changing the helper source.

Validation: focused positive, negative, paired-control, partial-rebuild, multi-helper ordering, hidden/incomplete/user-role, ownership, settings, and route tests; real unpacked-Chrome refresh with a trusted end-control click, start-control Close/Reopen, multiple diagrams, automatic-preview resumption, and zero backend/composer side effects; full automated suite.

Assets: unpacked Chrome extension ZIP, complete source ZIP, and SHA256SUMS.txt. Unzip the extension ZIP and reload it in chrome://extensions. Existing settings are preserved.
