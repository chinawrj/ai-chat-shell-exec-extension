# AI Chat Shell Exec v0.11.12

This release fixes installed Skills disappearing from **View Skills** under several catalog and multi-tab conditions.

## Complete local Skill inventory

`View Skills` now renders exactly one row for every successfully discovered Skill. Installation is per-row metadata and never a management-list filter: installed, uninstalled, missing-installer, and lifecycle-action states remain visible together.

The smaller catalog-size bound used to protect AI/composer protocol replies no longer blanks the local management list. If that bound is exceeded, the AI catalog still fails closed and no oversized data enters the composer, while the bounded local management UI continues showing all discovered rows read-only.

Invalid `SKILL.md` files remain explicit diagnostics rather than hiding valid Skill rows.

## Durable installed state

A partial or invalid scan can no longer destructively reconcile persistent installation state. Temporarily missing configured roots, a populated default root that disappears, traversal failures, malformed neighboring Skills, and other non-authoritative inventories leave authenticated receipts and the last valid catalog state untouched. A default root that has never existed remains a healthy empty catalog. When the exact root returns, installed rows recover without a false reinstall or catalog-version increment.

Complete valid scans still reconcile real add/delete/modify changes, and changed Skill or installer identities still fail closed as uninstalled.

## Live multi-tab View Skills

An already-open **View Skills** dialog now follows catalog version, SHA, and count changes made by another tab. Refresh is single-flight and latest-only: unchanged polling does no work, stale responses cannot roll back a newer list, a legitimate catalog-state repair may reset the version, local install/uninstall retains dialog ownership even when it starts during a pending refresh, closing or navigating invalidates an in-flight response, and both rejected and resolved background failures preserve the previous rows with a visible error. These updates stay local and never write to the AI composer.

## Validation

- Mixed installed/uninstalled management inventory equality checks.
- Oversized AI catalog with an authenticated installed row still visible locally, while the AI list remains empty.
- Partial-invalid and explicit/default temporarily missing-root receipt/state preservation plus exact recovery, while retaining the never-created default-root behavior.
- Positive and negative dialog refresh tests covering single-flight, unchanged state, version reset, stale response, resolved/rejected failure, close, and pre-existing/late-starting lifecycle ownership.
- Real unpacked-Chrome two-tab install, uninstall, and reinstall transitions without reopening View Skills or touching the composer.
- Full repository test suite and independent release review.

This release uses shell server protocol 12 and Skill protocol 5. Restart the foreground server, reload the unpacked extension, and refresh affected chat tabs after upgrading.
