# AI Chat Shell Exec v0.10.1

This release makes the file-helper destination configurable and adds one complete AI instruction document designed for direct use in chat-product Custom Instructions.

## Configurable file-helper destination

- If `AI_HELPER_FILE_PATH` exists in the shell server environment, every `ai-helper-file` request writes its single named file directly into that directory instead of `$HOME/Downloads`.
- If the variable is absent, the existing `$HOME/Downloads` default is unchanged.
- An explicitly empty or whitespace-only value is rejected instead of falling back to an unintended directory.
- Existing filename safeguards remain intact: the helper accepts only one filename and rejects paths, traversal, null bytes, and nested destinations.

Start the server with an override such as:

```sh
AI_HELPER_FILE_PATH=/path/to/helper-files ./scripts/start_shell_server.sh
```

## Unified AI Custom Instructions

`docs/AI_INSTRUCTIONS_FULL.md` is a single cohesive instruction set that can be pasted directly into an AI chat product. It covers:

- shell, board, file, and Draw.io helpers;
- execution, queue, recovery, interruption, and retry semantics;
- Master/Slave roster, delegation, status, and reply helpers;
- role-aware tmux routing, safety confirmation, and composer-delivery behavior.

Unlike `docs/AI_INSTRUCTIONS.md`, the new file is not a menu of Minimal, Recommended, one-off, or role-specific templates. Conditional Master/Slave behavior is integrated into the same instruction set.
