# AI Chat Shell Exec v0.11.13

This release makes the compact extension panel's current lifecycle state visible at a glance without making the default panel larger.

## Semantic panel backgrounds

- Idle keeps the existing charcoal background and border unchanged.
- Running helper work uses a low-saturation deep blue background and blue border.
- User-visible completion uses a low-saturation deep green background and green border.
- Failures and actionable exceptions use a low-saturation deep red background and red border.

The existing status dot and explicit status text remain. The status text now also carries an `Idle`, `In progress`, `Completed`, or `Error` accessibility prefix, so the meaning does not depend on color alone.

## End-to-end lifecycle rules

Shell, file, board, agent, Skill, and Draw.io helpers share the same visual state contract. A successful backend result that is still waiting to be delivered through the chat composer remains blue because the helper is not yet complete for the user. Once a fresh matching submitted-message proof exists, it remains green even if only the server presentation receipt must still be retried. A backend or protocol failure becomes red immediately even if its bounded error reply is still waiting for the composer. Output-idle shell execution remains blue while the user chooses Continue waiting or Stop helper. Ctrl+C after execution began remains an executed terminal result and therefore becomes green after its result is presented.

Draw.io rendering explicitly starts blue, becomes green only for the latest accepted artifact, and becomes red for the latest validation or renderer failure. Cancelled or superseded renderer promises cannot overwrite a newer helper state; when the latest decision intentionally restores an already-rendered artifact over a cancelled staging replacement, the panel returns to green.

## Validation

- Focused unit/source regressions cover exact theme values, unchanged idle behavior, success-pending versus failure-pending delivery, Skill operation labels, accessibility text, and stale Draw.io ownership.
- Real unpacked-Chrome coverage checks computed panel background and border colors during idle, running, output-idle, Ctrl+C completion, Draw.io success, and Draw.io failure.
- README screenshots are generated by the same real Chrome E2E path.

This release uses shell server protocol 12 and Skill protocol 5. Reload the unpacked extension and refresh affected chat tabs after upgrading; the shell server does not require a protocol change for this release.
