# AI Chat Shell Exec v0.11.20

Every complete Draw.io helper now has a trusted **Preview** button beside its code block. This makes diagrams in existing conversation history available after a page refresh, including conversations where an earlier Skill helper previously caused the panel's Force run action to select the Skill instead.

Historical diagrams remain closed until Preview is clicked. The button opens the exact selected helper locally, preserves that manual selection across ordinary rescans, and reopens an existing render after Close without rendering it twice. A newly generated Draw.io helper resumes the normal automatic preview behavior. Force run continues to handle executable and Skill helpers.

Manual previews never run Skills, contact the shell backend, or write success or failure into the chat composer. Controls reject synthetic clicks and explicitly identified user messages. Settings changes, helper replacement or detachment, route changes, and stale renderer completion cancel the request locally.

Rendering ownership now follows the latest selected source even when two helpers contain identical XML. Stale success and error callbacks release their iframe and timers without replacing the current diagram or leaving a staging state.

Validation: focused positive, negative, ownership, same-XML, settings, route, user-role, cancellation, and recovery tests; real unpacked-Chrome page refresh with Skill-before-Draw.io history, trusted per-helper clicks, Close/Reopen, automatic-preview resumption, and zero backend/composer side effects; full automated suite.

Assets: unpacked Chrome extension ZIP, complete source ZIP, and SHA256SUMS.txt. Unzip the extension ZIP and reload it in chrome://extensions. Existing settings are preserved.
