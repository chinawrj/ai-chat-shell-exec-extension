# AI Chat Shell Exec v0.10.5

This release makes Draw.io behavior match the latest complete helper exactly.

- A successful latest helper displays its SVG, clears any previous error, and does not reply to the AI.
- A malformed helper or renderer failure clears the older SVG and download action, keeps only the latest error in the preview, and sends a bounded error report through the existing reliable composer-delivery path.
- Repeated scans and DOM redraws do not resend the same Draw.io error.
- The preview now has a real **Maximize** button that fills the browser viewport and switches to **Restore**.
- Draw.io helper selection does not depend on the optional author-role filter; explicitly identified user messages remain ineligible.

The shell server protocol remains version 10 and the helper protocol remains version 3, so this release does not require a server protocol upgrade.
